Quay game trên máy AMD nhẹ hơn mà vẫn giữ nguyên độ nét và 60 khung/giây.

- Máy Radeon tích hợp không nhận hình trực tiếp giờ để GPU tự đổi màu và thu nhỏ hình, không còn chép cả khung hình về RAM cho CPU làm. Việc này nặng nhất trên các máy đó, game được nhường lại CPU
- Bộ mã hoá AMD chạy ở chế độ nhanh và độ trễ thấp, độ nét giữ nguyên, file có thể lớn hơn một chút
- Máy NVIDIA và Intel không đổi gì
