- Ghi micro không còn làm Windows giảm tiếng game: trước đây Windows coi micro của tai nghe là cuộc gọi và tự hạ mọi âm thanh khác 80%
- Tai nghe Bluetooth: micro để Mặc định thì Recora dùng micro khác (webcam, micro rời) thay cho micro của tai nghe, để tai nghe không chuyển sang chế độ gọi. Chỉ có micro tai nghe, hoặc bạn tự chọn nó, thì Recora báo rõ vì sao tiếng game nhỏ đi
